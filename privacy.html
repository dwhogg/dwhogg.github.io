Privacy Policy

Last updated: November 25, 2026

hermes-mail ("the app") is a personal, self-hosted tool. It is operated by one individual ("the owner") solely to process the owner's own email. It is not offered to the public. This policy explains what data the app accesses and how it is handled.

Data the app accesses

With the owner's explicit permission, granted through Google's sign-in screen, the app uses the Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly. This allows it to read:

  • email messages, including headers, body text and attachment names, in the owner's own Gmail account
  • the account's labels and the history of label changes
  • the account's email address, used only to confirm the correct account was signed in

The app cannot send, modify or delete email, and it does not request any other Google data.

How the data is used

  • To save selected messages, such as messages with a chosen label, as notes in the owner's private notes.
  • To produce summaries, digests and alerts (for example, about important, time-sensitive or likely fraudulent messages) for the owner.
  • To keep a private log of which messages were processed and why, so the owner can review and correct the app's decisions.

The data is used only to provide these features to the owner. It is not used for advertising, sold, or used to build profiles of anyone.

Storage and security

  • Data is stored only on computers controlled by the owner and in the owner's private, synchronised notes.
  • Google sign-in tokens are stored on the owner's server with access restricted to the app.
  • Email bodies that are not selected for keeping are deleted from the app's working storage after a short retention period, typically 21 days. A small record of each message (such as sender, subject, date and a short summary) is kept in a private log.

Sharing with third parties

The data is not shared with anyone, with one exception: to produce summaries and classifications for the owner, message content may be sent to a third-party AI model provider chosen by the owner. This is done only to provide those features to the owner, and the content is processed under that provider's terms.

Google API Services User Data Policy

hermes-mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and deleting data

Access can be removed at any time at myaccount.google.com/permissions. After access is removed, the app can no longer read the account. Because all stored data belongs to the owner, the owner can delete it at any time.

Changes

This policy may be updated as the app changes. The date at the top shows the latest version.
